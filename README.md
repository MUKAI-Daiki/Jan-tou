# 雀闘：仮

麻雀の役づくりと点棒のやり取りを、コマンド型の数値戦闘に置き換えたブラウザゲーム（MVP）。

## 起動

```sh
npm install
npm run dev      # 開発サーバ
npm test         # 単体テスト（面子分解・役・符・ダメージ・戦闘進行）
npm run build    # dist/ に静的ファイルを出力
```

ランタイム依存はゼロ（devDependencies は vite / typescript / vitest のみ）。

## 構成

| パス | 役割 |
|---|---|
| `src/core/tile.ts` | 牌の定義（ID 0..135、種類 = id>>2） |
| `src/core/mentsu.ts` | 面子分解の列挙、暗槓候補 |
| `src/core/yaku.ts` | 3面子版の役判定 |
| `src/core/score.ts` | 符・満貫〜役満ダメージ、選択牌の評価 |
| `src/core/battle.ts` | 戦闘の reducer `step(state, action)`（純粋関数） |
| `src/core/monster.ts` | モンスター行動 |
| `src/data/monsters.ts` | モンスター・HP・技（バランス調整はここ） |
| `src/ui/` | 描画と CSS |

## ルール要点

- 使用牌：筒子9種・索子9種・三元牌（白發中）3種の計21種84枚（萬子・風牌は不使用）
- 手牌8枚（自模を含めて9枚）。自模 →（暗槓・攻撃：1ターンに何度でも可）→ 打牌 → モンスター行動
- 連続攻撃（Chain）：1ターン中に攻撃するたびChain数が+1され、ダメージに ×(Chain数+1) の補正がかかる（打牌でリセット）
- ダメージ：（4翻以下は ceil100(4 × 符 × 2^(翻+2))（上限8,000）、5翻＝満貫(8,000)、6〜7翻＝跳満(12,000)、8〜10翻＝倍満(16,000)、11〜12翻＝三倍満(24,000)、13翻以上＝役満(32,000)）× 面子数倍率（1面子:×1、2面子:×2、3面子・七対子:×3）
- 符 = ceil10(20 + 面子符)（七対子は25符固定）
- 1面子は役なしでも攻撃できる（三元牌の刻子は役牌1翻）。2〜3面子または七対子（対子4組）は役が必要
- 七対子は異なる対子4組（8枚）で成立し、連続する3種の対子を含めば一盃口とも複合する
- 染め手（混一色・清一色）は3面子での攻撃時のみ複合する
- 役満は13翻として計算し、複数成立した場合は加算する
- 副露した暗槓は単独では攻撃できない（役牌は除く）。捨てたときの補充は3枚
